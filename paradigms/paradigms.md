# Programming Paradigms

This directory explores programming paradigms through practical implementations, comparisons, and engineering trade-offs.

The objective is not merely to learn paradigm definitions, but to understand how programming style influences code organization, extensibility, complexity, and maintainability.

## Contents

| File | Focus |
|---|---|
| `OOPS.java` | Object-oriented design, abstraction, and polymorphism |
| `POP.java` | Procedural decomposition using functions |
| `POP_VS_OOP.md` | Comparative analysis and design trade-offs |
| `FunctionalProg.java` | Planned: functional concepts and immutable transformations |

## Guiding Principles

- Prefer the simplest design that adequately solves the problem.
- Evaluate abstractions based on actual requirements.
- Understand trade-offs rather than treating paradigms as competing rules.
- Keep examples executable and explain why a design is useful.

## Running the Java Examples

Compile and run each example from this directory:

```bash
javac OOPS.java
java OOPS

javac POP.java
java POP
```

Each Java example uses its own public class and can be compiled independently.
